## 必须先确认的设计边界

1. **指标兼容**：旧 evaluator 把未映射预测归入 Other，并可能计入错误分母；新规则要求未映射单列、不计错误。建议在原框架新增版本化指标模式，保持历史结果原样，同时报告映射覆盖率和分母，避免“排除越多、准确率越高”的误读。
2. **项目兼容**：当前严格实现 hash 与 1.0 补丁兼容要求并不完全一致。建议只对证实不影响科学结果的变化提供明确确认和环境差异 receipt。仅凭“依赖小版本”不足以判断科学等价；完整性破坏和科学代码变化仍阻断。
3. **第一关前诊断 PCA**：当前策略页面承诺审批前不运行 PCA。新功能需要修改这一承诺：仅允许可复现、无自动决策效力的诊断计算；最终分析仍经批准后执行。需随功能 PR 明确修改界面、参数和实现 hash。
4. **Harmony 的保存范围**：Harmony 改嵌入、不改 RNA counts/data。RNA 差异结果不变是完整性检查，不能作为没有过度校正的证据；须另测嵌入中的条件和类型信号。

以上均为待确认的设计建议，没有为绕过现有约束而改代码。
