# scAgentKit 定位 v2

2026-10-20。供维护者、合作者、验证者、审稿人及在仓库工作的 Codex 使用。本文定义目标和可支持的论证，不把尚未完成的功能或实验写成已验证结果。当前完成程度见阶段报告及[论文里程碑计划](PAPER_MILESTONE_PLAN.md)。

## 一句话

scAgentKit 是一个面向长期研究使用的、受控的 LLM 单细胞基础分析助手。它把从 QC 到注释的关键科学决策显式化，并按生物学设计做判断。每项决策由 LLM 结合研究目的起草并附上可核对的证据，由研究者批准，最终产出可审计、可复现的结果。

English: scAgentKit is a governed LLM assistant for foundational single-cell RNA-seq analysis, built for long-term research use. It makes every decision-critical step from QC to annotation explicit and biologically informed: the LLM drafts each decision from the research goal with verifiable evidence, the researcher approves it, and the result is auditable and reproducible.

## 用户和范围

目标用户有生物学背景、但不熟悉生信，需要能够理解、解释、写进论文并在后续研究中反复使用的结果。

范围是原始计数矩阵到注释好的 Seurat 对象，以及随对象交付的审计证据。依赖研究目的的高级分析（轨迹、细胞通讯、调控网络、条件间差异表达、细胞组成比较）不在范围内。条件信号诊断用于判断基础分析是否抹掉设计信息，不变成新的下游条件 DE 功能。

论文完成前不新增分析类型、MCP 入口或本地模型。

## 三个核心卖点及所需证据

| 卖点 | 产品含义 | 证明方式 |
| --- | --- | --- |
| 生物学上合理的决策 | 多样本 QC；有资格和审批的诊断簇阈值；以实验设计和观测效应判断批次必要性；按目的处理双细胞和周期 | 低 RNA 类型保留、假/真/混杂批次、多样本深度、双细胞/周期等预定错误注入；技术混合与生物学保留分报 |
| 决策显式化且可复现 | QC、双细胞、周期、批次、分辨率、注释可见、可改、可追溯；固定输入/决策/环境的结果可重放 | 重复运行稳定性、同输入端到端对照、无 API 离线重放；记录随机种子与环境，temperature 0 不被当作线上确定性保证 |
| 证据可核对 | 结论由该数据的统计结果核对，校验器确定性执行 | 引用有效率、置信度分组表现、弃权；格式或统计引用有效不等于已证明整段生物学解释正确 |

支撑能力是三道审批前的 LLM 草稿与理由、难簇 ReAct 查证、本地按物种/组织筛选的 ACT 独立对照及 CL 映射，以及多样本、raw/filtered 10x、样本表/RDS、设计声明、持久项目恢复。规则兜底和人类审批贯穿其中；保存不等于批准，LLM 永远不能批准。

## 比较边界

注释工具候选（GPTCelltype、CASSIA、CellTypeAgent、mLLMCelltype）用于固定细胞/聚类/marker 和底座模型的注释对照；自主 agent 候选（CellAgent、Biomni 等）用于经核实版本及功能后的适用比较。不能仅凭工具类别推断其全部能力。

描述其他工具时统一使用“未将 X 作为显式、可审阅的决策”，不写“不考虑 X”；每项具体比较须有被测试版本的原始来源。scAgentKit 的定位是比只提供注释的工作流覆盖更多基础分析决策，并通过审批和确定性核验追求可靠性；“比自主 agent 更可靠”需要正式比较证据后才可作为结果陈述。

不主张注释准确率最高、全自动或任意下游分析能力。范围更大本身不证明准确率更好；同模型的注释对照与 raw counts 端到端对照分别报告。

## 其他定位证据

| 主张 | 对应证据与限制 |
| --- | --- |
| LLM 辅助有价值 | accept_drafts/rule_defaults 与 ReAct 开关消融；真人研究再测采纳率、耗时、一致性。脚本固定采纳不能充作真人采纳率 |
| ACT 有价值 | ACT 开关消融；冲突是否预示错误；未评估单列，关联不等于因果 |
| 注释不差 | 相同底座和基准与至少一个合格 LLM 注释工具比较；配合参考分类器，报告覆盖和分母 |
| 长期真实使用 | 作者已发表研究案例和外部验证者记录；便携审计与补丁兼容的 1.0 工作；不以一次试跑替代 |
| 模型未见数据 | 维护者未公开留出集的可核验来源、开发隔离和冻结双标签；公开数据训练后首次发布为优先补充 |

必须同时守住快速审批与拦截错误：通常一键采纳草稿，同时能检查和拒绝错误。两者都需要证据；更多弹窗不自动等于更受控。
