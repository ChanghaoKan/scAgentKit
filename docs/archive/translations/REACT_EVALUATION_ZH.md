# 比较与离线重放注释草稿

ReAct 查证后的标签仍是草稿，需要你在第三道审批中批准。下面的评估和重放
不修改分析结果、不批准草稿，也不需要 API key。

## 比较标签

准备 `cell_id,label` CSV；若使用项目原有的簇，也可以提供 `cluster_id,label`。
外部工具重新聚类时必须使用细胞 ID，不能直接比较不同分区的簇编号。

```r
result <- sc_react_eval(
  "my-project", truth = "truth.csv",
  external = list(SingleR = "singler.csv", CellTypist = "celltypist.csv")
)
result$metrics
result$output_dir
```

输出比较一次性草稿、ReAct 草稿和外部预测，分别报告全部簇、被查证的难簇，
并附细胞级结果。之后的人工修改不计入这次草稿比较。细胞标签汇总为簇标签时，
至少 80% 的细胞须成功映射，其中至少 80% 支持同一类型。

标签通过本地 Cell Ontology 映射；可以用 `label_map` 提供预先冻结的名称对应表，
或提供与标签映射一致的 `cl_id` 列。主要准确率排除未映射预测，严格版将其计为错误，
两者并列展示。Unknown 在两种分母中都保留。结果包含映射覆盖率和分母。

父类计分需要预先冻结 `allowed_ancestors`：只有这些有生物学意义的 CL 父类、
且距离真值不超过三条父类边时才算匹配。无依据的更细亚型和泛化到“细胞”这样的
根类别都不获得父类分数。未提供该列表时，只计完全匹配。

两份独立人工真值可使用 `cell_id,label_author,label_independent`，可选
`cl_id_author,cl_id_independent`。共识取完全一致的类型，或唯一最近的允许共同父类。
分歧单独列出，不计入主要细胞准确率；同时分别对两位注释者计分。留出集标签与映射表
应在工具首次运行前冻结。

结果还包含每簇步数、回退原因、工具开关、映射来源、实际记录的 token 和费用。
未知费用明确标注。当前一次性费用统计覆盖项目内所有注释调用，ReAct 增量只统计
当前保存的会话；外部 CSV 不提供运行费用，需要另行收集。不做费用预计或预算预留。

## 不调用模型的重放

```r
replay <- sc_react_replay("my-project")
replay$matches
replay$differences
```

重放重建保存的完整消息历史，重新执行只读工具、核对引用，并返回原始草稿和差异。
需要保留原项目检查点与相同科学实现版本；输入缺失或完整性破坏会阻断。
人工编辑后的最终表不属于原始草稿重放。

缓存命中标记不影响一致性。超时等依赖运行环境的失败可能无法逐字复现；
发送前失败若没有投递回执，也会明确列为无法核实的差异，不会声称完全一致。
