# Focused development examples

These focused/historical drivers were moved from installed examples to reduce the user entry points. They are repository resources excluded from package archives. Run maintained drivers from the repository root; shared example helpers resolve in `dev/examples`, optionally overridden by `options(scAgentKit.dev_examples="/absolute/repository/dev/examples")`.

The installed user examples are the three-gate public software control and its simple wrapper, a complete configured-model browser entry, explicit multi-sample 10x entry, and scoped subcluster review. Historical scripts can refer to retired APIs; they are not an alternative current workflow or evidence that a platform/provider was accepted.
